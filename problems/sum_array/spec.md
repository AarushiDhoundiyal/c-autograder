# sum_array

The first integer `n` (0 <= n <= 100000) is the number of values. Then `n` 32-bit integers follow,
separated by whitespace/newlines. Print their sum followed by a newline.

The sum may exceed 32 bits: the expected answer is the exact sum computed in `long long`.
Required time complexity: O(n). `n = 0` prints `0`.
