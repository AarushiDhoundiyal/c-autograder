# Originality corpus

`similarity_flag` compares every submission with the `.c` files below this folder.

    corpus/peers/    other students' submissions (loose *.c here also count as peers)
    corpus/llm/      solutions generated by an LLM for the same problem (several seeds)
    corpus/online/   solutions you collected from the web

Replace the two examples with your own collected files. A file that is the
submission itself (same path) is ignored automatically.
